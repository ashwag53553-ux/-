# كيف تُشغَّل المهام بلا لصق نصوص طويلة

بدل لصق برومت طويل، اكتب في كلود المحلي أمراً واحداً:

| الأمر | ماذا يفعل |
|---|---|
| `/بطاقة` | يعرض حالة المشروع كاملة (يبني `state/SNAPSHOT.md`) |
| `/جرد` | يركّب المكينة ويجرد المشروع بالأرقام الحقيقية |
| `/مكتبة` | يفهرس المراجع، يشغّل OCR، يبذر بنك الشواهد |
| `/مطلب <الفصل والمطلب>` | يكتب المطلب ويمرّره على خطّ الإنتاج كاملاً |
| `/تسليم [ملفات]` | حُرّاس ← محكمة ← بناء المستند الأمّ ← فتح وورد |

كل أمر منها يقرأ `_SAFE_HEADER.md` أولاً، فلا يمكن أن يحذف ملفاً، أو ينشئ
ملف وورد ثانياً، أو يخفّض حارساً، أو يخترع مصدراً — حتى لو أُرسل بلا مراجعة.

الملفات الطويلة هنا (`00_`، `01_`، `02_`) هي متن هذه الأوامر، تُحرَّر عند
تطوير المنهج، ولا تُلصق يدوياً.
