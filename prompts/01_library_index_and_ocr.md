# مهمّة: بناء سجل المصادر الحقيقي + تشغيل خطّ OCR للمراجع الممسوحة

## القيود
- كل حقل في السجل مأخوذ من صفحة العنوان أو صفحة الحقوق **بعد فتح الملف فعلاً**.
- ما لم تجده: اتركه فارغاً واكتبه في `state/red_page.md`. **ممنوع التخمين.**
- لا تكتب محتوى الرسالة في هذه المهمة.

## الخطوة ١ — فهرسة آلية
```
pip install pypdf ocrmypdf
python tools/index_library.py --write
```
ألصق المخرج: عدد الملفات، القيود الجديدة، عدد الممسوح.

## الخطوة ٢ — إكمال البيانات يدوياً للكتب الأكثر أهمية
رتّب الكتب بحسب حاجتها في الفصل القادم، ثم لأول **١٥** كتاباً منها:
افتح صفحة العنوان وصفحة الحقوق، واملأ في `source_registry/registry.tsv`:
`العنوان الكامل، المؤلف، المحقق، الطبعة، الدار، المدينة، السنة، عدد الأجزاء، عدد الصفحات`
وحقل `التصنيف` بواحدة من: `معنا` / `ضدنا` / `محايد`.

## الخطوة ٣ — OCR
```
python tools/ocr_library.py --limit 3     # تجربة أولاً
python tools/ocr_library.py --all
python tools/index_library.py --write     # إعادة الفهرسة بعد OCR
```
إن فشل OCR: اذكر رسالة الخطأ الحقيقية وسببها الجذري (نقص Tesseract؟ حزمة `ara`؟ PATH؟)
وعالجها، ولا تتجاوزها بصمت.

## الخطوة ٤ — بذر بنك الشواهد
من الكتب الخمسة الأهم للفصل القادم، استخرج **١٥ شاهداً حقيقياً** إلى
`evidence_bank/quotes.tsv` بالحقول كاملة (نصّ الشاهد كاملاً + الصفحة + التصنيف).
شرطُ القبول: تكون قد فتحت الصفحة وقرأتها. أي شاهد غير مؤكد ← الصفحة الحمراء.

## الخطوة ٥ — التحقّق
```
python guards/citation_court.py
python tools/thesis.py status
```
ثم اختم بتقرير التحقّق (CLAUDE.md §٦)، وحدّث `state/ledger.md`.
