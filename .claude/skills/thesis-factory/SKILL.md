# مصنع الرسالة

## القاعدة الأولى
اقرأ `CLAUDE.md` في جذر المشروع قبل أي شيء، والتزم قواعده الستّ حرفياً.
إن وُجد `chapters/<الفصل>/EXCEPTIONS.md` فهو وحده ما يتجاوز الدستور، ولفصله فقط.

## متى تستعمل هذا السكيل
أي عمل يمسّ نصّ الرسالة أو مراجعها أو مستندها الأمّ.

## الخطوات الثابتة

### ٠) أول خطوة في كل جلسة
اقرأ `state/SNAPSHOT.md` (بطاقة المشروع) — فيها حال المشروع كله في صفحة واحدة.
لا تفتح ملفاً إلا لِما لم تُجب عنه البطاقة. وأعِد بناءها بعد أي تعديل:
`python tools/snapshot.py`.

### ١) قبل الكتابة
- اقرأ `outputs/matalib/00_preliminary_chapter_REVIEW_AUTHENTIC_RESEARCHER_VOICE.md`
  لضبط الصوت والنبرة.
- اقرأ `source_registry/registry.tsv` و`evidence_bank/quotes.tsv` **قبل** فتح أي كتاب:
  الشاهد المسجَّل يُعاد استعماله، ولا يُستخرج مرتين (اقتصاد توكنز وجودة أعلى).
- راجع `state/ledger.md` لتعرف أين وقف العمل.

### ٢) أثناء الكتابة
- اكتب في Markdown داخل `chapters/` فقط. لا تُنشئ ملف وورد بيدك أبداً.
- لغة المصنع: `#`باب `##`مبحث `###`مطلب، الهامش `[^١]` وتعريفه في آخر الملف،
  الاقتباس `>`، كسر الصفحة `<<<pagebreak>>>`، الأرقام عربية شرقية.
- الحلقات والمقاطع في المتن مختصرة، والهوامش للكتب والمقالات فقط.
- كل شاهد جديد يُقيَّد فوراً في `evidence_bank/quotes.tsv`،
  وكل دعوى مقطع في `evidence_bank/clips.tsv` بتوقيتها الحقيقي من ملف SRT.
- كل ما لم يثبت: `[[تحقق]]` + بند في صفحة التحقّق الحمراء.

### ٣) بعد الكتابة — خطّ الإنتاج
```bash
python tools/thesis.py check <الملف>              # الحُرّاس
python tools/thesis.py ship  <الملفات> --open      # حُرّاس ← محكمة ← بناء ← تقرير
```

### ٤) الخطوط الحمراء
- **ممنوع** تعديل `guards/` أو تخفيف عتباتها أو تعطيل فحص لتمرير نصّ.
  الرفض يُعالَج بإصلاح النصّ لا بإضعاف الحارس.
- **ممنوع** إنشاء ملف وورد ثانٍ أو نسخة «نهائية_٢».
- **ممنوع** اختلاق مصدر أو صفحة أو توقيت. الشكّ مكانه الصفحة الحمراء.

### ٥) الختام الإلزامي
اختم كل مهمّة بتقرير التحقّق (CLAUDE.md §٦) وحدّث `state/ledger.md`.

## أدوات المصنع
| الأداة | الوظيفة |
|---|---|
| `tools/thesis.py` | قائد خطّ الإنتاج (check / court / build / ship / status) |
| `tools/build_rtl_clean_docx.py` | محرّك البناء الوحيد: RTL + أرقام عربية + تنظيف |
| `guards/guard_check.py` | الحُرّاس السبعة على النصّ قبل اعتماده |
| `guards/citation_court.py` | محكمة الإحالات وبناء الصفحة الحمراء |
| `tools/snapshot.py` | بطاقة المشروع: كل شيء في صفحة واحدة بأقلّ التوكنز |
| `tools/index_library.py` | فهرسة مكتبة المراجع وكشف الممسوح |
| `tools/ocr_library.py` | خطّ OCR العربي للمراجع الممسوحة |
