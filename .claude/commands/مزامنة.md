نفّذ بالترتيب، وتوقّف عند أول فشل واشرح سببه:
1. `python tools/snapshot.py`
2. `python tools/thesis.py check chapters/**/*.md` (تقرير فقط، لا تُفشل الرفع)
3. `git add -A` ثم `git status --short` واعرضه لي.
4. `git commit -m "<وصف دقيق لما تغيّر فعلاً>"`
5. `git push -u origin claude/thesis-architecture-setup-r90xlb`
   (عند فشل الشبكة أعد المحاولة أربع مرات: ٢ثـ ٤ثـ ٨ثـ ١٦ثـ)

تنبيه: `.gitignore` يمنع رفع ملفات PDF والفيديو والصوت. لا تتجاوزه ولا ترفع
مواد ثقيلة. المرفوع نصوص فقط: مسودّات، تفريغات، سجلات، إعدادات.
