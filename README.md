# مكينة إنتاج الرسالة

نظام إنتاج لرسالة ماجستير عربية: مسودّات Markdown ← حُرّاس آليّون ← محكمة إحالات
← مستند وورد أمّ واحد بضبط RTL كامل وأرقام عربية شرقية ٠-٩ ومنها أرقام الحواشي.

## التركيب (مرة واحدة)

```bash
pip install python-docx pypdf
# اختياري لخطّ OCR:  pip install ocrmypdf   + Tesseract مع حزمة اللغة ara
```
ثم انسخ محتويات هذه الحزمة إلى جذر مجلّد العمل، واضبط المسارات في
`thesis.config.json` (`library_root`، `clips_root`، `chapter_order`).

## الاستعمال اليومي

```bash
python tools/thesis.py status                       # أين وصلنا
python tools/thesis.py check chapters/chapter02/*.md   # الحُرّاس
python tools/thesis.py ship  chapters/chapter02/*.md --open   # الخطّ كاملاً
```

## البنية

```

tools/thesis.py               قائد خطّ الإنتاج
tools/index_library.py        فهرسة المكتبة وكشف الممسوح
tools/ocr_library.py          OCR عربي للمراجع الممسوحة
guards/guard_check.py         الحُرّاس السبعة
guards/citation_court.py      محكمة الإحالات + الصفحة الحمراء
source_registry/registry.tsv  سجل المصادر (مصدر بيانات كل هامش)
evidence_bank/quotes.tsv      بنك الشواهد الحقيقية بصفحاتها
evidence_bank/clips.tsv       بنك دعاوى المقاطع بتوقيتاتها
state/ledger.md               لوحة الحالة للاستئناف بين الجلسات

prompts/                      برومتات جاهزة للتشغيل
.claude/skills/thesis-factory سكيل يقود الجلسات المحلية آلياً
```

## لماذا علامات حواشٍ مخصّصة؟

ترقيم الحواشي التلقائي في وورد يرسم أرقامه بحسب إعداد **الجهاز**
(Advanced ← Numeral)، لا بحسب المستند؛ فيظهر ١٢٣ عند شخص و123 عند آخر.
لذلك يبني المحرّك علامة حاشية مخصّصة نصُّها رقم عربي شرقي، ويعيد الترقيم
في كل بناء — فيثبت شكل الرقم على كل جهاز. هذه هي «طبقة الأرقام»
المستقلة عن «طبقة الاتجاه».
